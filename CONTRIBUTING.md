# Contributing

Feedback on claims, proofs, experiment design, reproducibility, and exposition
is welcome through GitHub issues or pull requests.

Before proposing a change:

1. identify the paper and claim in scope;
2. distinguish conceptual discussion from a change to a frozen numerical
   result;
3. preserve immutable source revisions and checksums; and
4. run the build or validation commands documented in that paper's README.

Do not edit a frozen summary by hand. Regenerate it from the recorded inputs
and include the validation output that explains the change.

Implementation changes belong upstream in their software repository. This
repository should pin the relevant commit or pull request and retain only the
material needed to reproduce the paper.
