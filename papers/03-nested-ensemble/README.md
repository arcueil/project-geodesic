# Paper 3 — The Nested Ensemble

## Working proposal

Paper 3 addresses targets for which one constant global metric is an inadequate
operational description: separated mixtures, funnels, and other posteriors with
persistent regional geometry.

The proposed architecture is nested:

- inner populations identify and exploit regional metric targets;
- an outer population mechanism exchanges information and mass across regions;
  and
- population-level diagnostics assess exploration without treating
  within-region agreement as global certification.

The single-region limit recovers the warmup and local-motion layers of Papers 1
and 2.

## Current status

Conceptual proposal. The general mixture and 25-mode mixture examples are
reserved for this paper. Method design, theory, implementation, and validation
remain open.
